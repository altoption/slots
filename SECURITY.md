# Security

Please report security problems privately, not in a public issue: use **Report a vulnerability** on
the [Security tab](https://github.com/altoption/slots/security/advisories/new) of this repository.

Useful to include: what you found, how to reproduce it, and what it affects (the plugin on a
player's machine, or the game server).

In scope: this plugin, and the game server it talks to (`terminal-slots.altoption.workers.dev`).
Please don't run load tests or automated scans against the server, and don't access other players'
data; a demonstration on your own account is enough.
